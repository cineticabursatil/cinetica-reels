# cinetica-reels

Reels públicos de Cinética Bursátil y narrador automático.

- `final/`: reels publicados (versión con música).
- `narraciones.json`: el texto que lee la voz en cada escena (edítalo y se regeneran solos).
- `narrar_reels.py`: quita la música y pone la voz sintética (edge-tts + FFmpeg).
- `final_voz/`: resultado generado por GitHub Actions (pestaña **Actions → Narrar reels con voz**).

Solo contenido público. Nada de material de alumnos ni privado.
